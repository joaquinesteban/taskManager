# 🗂️ TaskManager — Gestor de Recordatorios

**TaskManager** es una aplicación web sencilla y práctica para crear, editar y eliminar recordatorios o tareas del día a día.  
Permite mantener una lista organizada de pendientes directamente en el navegador, con almacenamiento local para que tus tareas se conserven incluso después de cerrar la página.

---

## 🚀 Funcionalidades principales

- 📝 **Agregar tareas:** ingresá recordatorios fácilmente desde el formulario.  
- ✏️ **Editar tareas:** modificá una tarea existente sin tener que borrarla.  
- ❌ **Eliminar tareas:** borrá las que ya completaste o no necesitás.  
- 💾 **Almacenamiento local:** tus recordatorios se guardan automáticamente en `localStorage`.  
- 🌗 **Modo oscuro y claro:** cambiá el tema visual según tu preferencia.
